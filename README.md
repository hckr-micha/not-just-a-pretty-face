# NOT JUST A PRETTY FACE
One-page site: HTML + CSS + vanilla JS. Open the folder in VS Code and run **Live Server** on `index.html`.

```
index.html    css/style.css    js/script.js    assets/images/
```
Sources, cards, timeline, facts, laws, hero photo settings and reminders are all at the top of `js/script.js`. Each card shows its own source links.

## Photos (assets/images/, exact names, .jpg)
- Hero: `hero1.jpg` to `hero20.jpg` (4 show at a time; upload 5+ for variety). Extra alt text: `HERO_ALT`.
- Timeline: `timeline-1920s-1.jpg` (+ `-2`), same for 1950s, 1980s, 2000s, 2020s. Credits: `credit` in `TIMELINE`.
- Reality: `reality-1.jpg` to `reality-4.jpg`.
Edit each photo's `alt` text in `script.js` to describe the real picture.

## Game text
Words in the game: `T` (titles, messages, buttons, K.O.!) and `BANK` (stereotype / truth pairs) in `js/script.js`. Labels "MONSTER" and "SCORE", the help line under the controls, and the alt text are in `index.html`.
